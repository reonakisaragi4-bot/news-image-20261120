A one-image summary of Friday 20 November 2026 world news, drawn as a crisp front-page poster: a masthead, a world map with a dot per story, and a 5×6 grid of 30 stories — every one verified as an event that happened or was first reported on 20 November 2026.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`draw_poster.py` renders `entry.png` (1024×1024, deterministic, no network); `main.ts` copies it to the output directory.
